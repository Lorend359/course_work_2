# Проект: Поиск и управление вакансиями с HeadHunter API

## Описание проекта
Этот проект позволяет получать информацию о вакансиях с платформы [HeadHunter (HH.ru)](https://hh.ru/) с использованием API. 
Функционал включает:
- Аутентификацию через OAuth 2.0 и управление `access_token`.
- Поиск вакансий по ключевым словам.
- Сохранение вакансий в JSON-файл.
- Удаление сохранённых вакансий.
- Просмотр сохранённых вакансий.


---
## Технологии и зависимости
- Python 3.10+
- `requests` — работа с HTTP-запросами.
- `dotenv` — управление переменными окружения.
- `flask` — обработка callback для получения `authorization_code`.
- `pytest` и `pytest-cov` — тестирование и анализ покрытия кода.

### Установка зависимостей
Перед запуском проекта установите зависимости с помощью Poetry:
```bash
poetry install
```

## Подготовка перед запуском
### 1. Регистрация приложения на HH.ru
Перед использованием необходимо зарегистрировать приложение в [кабинете разработчика HH.ru](https://dev.hh.ru/), получить `CLIENT_ID` и `CLIENT_SECRET`.

### 2. Настройка переменных окружения
Создайте файл `.env` в корневой папке и добавьте в него:
```env
HH_CLIENT_ID=ВАШ_CLIENT_ID
HH_CLIENT_SECRET=ВАШ_CLIENT_SECRET
HH_REDIRECT_URI=http://127.0.0.1:8000/callback
```

### 3. Запуск callback-сервера
Перед авторизацией запустите сервер для обработки `authorization_code`:
```bash
python src/callback_handler.py
```

### 4. Получение `authorization_code`
Перейдите по ссылке:
```url
https://hh.ru/oauth/authorize?response_type=code&client_id=ВАШ_CLIENT_ID&redirect_uri=http://127.0.0.1:8000/callback
```
После входа на HH.ru появится `authorization_code`, который нужно ввести в `main.py`.

## Запуск проекта
### 1. Запуск основного скрипта
```bash
python main.py
```
Программа предложит выбрать действие:
- **1**: Поиск вакансий.
- **2**: Сохранение вакансии.
- **3**: Удаление вакансии.
- **4**: Просмотр сохранённых вакансий.
- **5**: Выход.

### 2. Пример работы
```
Добро пожаловать в поиск вакансий на HH.ru!
Введите authorization_code: <ваш_код>
[LOG]: Успешная авторизация! Токен сохранён.

Выберите действие:
1. Поиск вакансий
2. Сохранить вакансию
3. Удалить вакансию
4. Показать сохранённые вакансии
5. Выход
```
